# Bias in AI

## The Bias Laboratory

Treat this as an experiment rather than beginning with an accusation. Groups
use prompt templates in which only one variable changes.

For a text-generation example, compare equivalent fictional candidates while
changing only a name. Record differences in adjectives, assumed
characteristics, and recommendations.

For an image-generation example, repeat prompts such as:

- Generate a successful CEO.
- Generate a kindergarten teacher.
- Generate a brilliant computer scientist.

Students count visible patterns across multiple results and ask:

> Where might these patterns have come from?

This creates the conceptual chain:

> training data → learned patterns → generated output

One output is not evidence of a systematic pattern. Students need controlled
comparisons and repeated observations.
