# Informatik PIA

Teaching materials and classroom projects for computer science.

## Raspberry Pi Pico Python workshop

**[Open the five-day slide website](https://danielsc.github.io/informatik-pia/)**

The workshop teaches Python through physical computing with a Raspberry Pi
Pico, Thonny, and the Freenove FNK0063 kit. Start with the
[workshop overview](Raspberry%20Pi%20Pico/Pico%20Python%20Workshop/README.md)
for the daily sequence and classroom instructions.
