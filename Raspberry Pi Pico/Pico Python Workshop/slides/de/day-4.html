Fehlende Daten

None bedeutet „keine brauchbare Messung“

In Thonny ausprobieren · Sagt beide Wege voraus


distance = measure_distance_cm()

if distance is None:
    print("No echo")
else:
    print(distance)

Wenn bei einem Fehler 0 verwendet wird, bedeutet das fälschlich: „Der Gegenstand berührt den Sensor.“

TEALS führt None mit Funktionsrückgaben ein. Vergleicht „kein Wert“ mit der gültigen Zahl null und lasst beide Zweige zeigen.

Timeouts

Warten braucht eine Grenze

Besprechen · Was passiert, wenn nie ein Echo zurückkommt?


pulse_us = time_pulse_us(echo, 1, ECHO_TIMEOUT_US)

if pulse_us < 0:
    return None

Der Timeout lässt das Programm einen Fehler melden und weiterlaufen, statt ewig zu warten.

time_pulse_us ist eine vorgegebene API. Die Klasse soll das Verhalten erklären, aber die Implementierung nicht nachbauen.

Warum ein Transistor?

GP15 steuert, versorgt den Buzzer aber nicht

Anschauen und besprechen · Zeigt beide Wege im Schaltplan

Steuerweg

GP15 → 1-kΩ-Widerstand → Transistorbasis B

Stromweg

VBUS → Buzzer → Kollektor C → Emitter E → GND

Verbindet den Buzzer nicht direkt mit GP15.

Der Transistor ist ein elektronischer Schalter. Mehr Transistorphysik ist für den sicheren Aufbau nicht nötig.

Teil 3 · Konfiguration

Speichert Einstellungen in einem Dictionary

Ein Zustandsname führt zu allen Einstellungen dieses Zustands.

Folgt TEALS Einheit 6: Schlüssel-Wert-Paare, Zugriff und Änderung vor verschachtelten Strukturen. Beginnt mit einem flachen Dictionary.

Schlüssel-Wert-Paare

Ein Dictionary beschriftet jeden Wert

In Thonny ausprobieren · Verwendet die Shell


zone = {"colour": "amber", "pause_ms": 600}

print(zone["colour"])
print(zone["pause_ms"])

Schlüssel

"colour" ist die Bezeichnung, mit der ein Wert gefunden wird.

Wert

"amber" ist die unter diesem Schlüssel gespeicherte Einstellung.

Lasst beide Schlüssel und Werte benennen. Die eckigen Klammern dienen hier dem Zugriff und sind kein Listenindex.

Eine Einstellung ändern

Ersetzt den Wert über denselben Schlüssel

In Thonny ausprobieren · Sagt das fertige Dictionary voraus


zone = {"colour": "amber", "pause_ms": 600}
zone["pause_ms"] = 400
print(zone)

Der Schlüssel bleibt "pause_ms"; sein Wert ändert sich von 600 zu 400.

TEALS behandelt weitere Methoden; diese kurze Lektion braucht nur Zugriff und Änderung. Überladet die Klasse nicht.

Mehrere Alarmzustände

Ein Zustand wählt ein Einstellungs-Dictionary

Anschauen und besprechen · Lest von außen nach innen


ZONE_CONFIG = {
    "safe": {"beep_ms": 0, "pause_ms": 300},
    "caution": {"beep_ms": 80, "pause_ms": 520},
    "stop": {"beep_ms": 80, "pause_ms": 120},
}

pause = ZONE_CONFIG["caution"]["pause_ms"]

Wählt zuerst "caution" und lest dann "pause_ms" aus: 520.

Verschachtelte Dictionaries sind eine Workshop-Erweiterung. Verfolgt genau einen Zugriff, bevor ihr den Alarmcode zeigt.

Beide Einzelschaltungen sollten vor diesem Abschnitt bestanden haben.

Ohne USB bauen · Tagesaufgabe

Sensor und Buzzer gemeinsam

Genauer Schaltplan + Tabelle
Dieser Schaltplan gehört zu 03_proximity_alarm.py. Der geprüfte Spannungsteiler bleibt, die geprüfte Buzzer-Schaltung kommt hinzu. Die eingebaute LED liefert die sichtbare Ausgabe.

Schichtweiser Aufbau · Tagesaufgabe

Vor dem Kombinieren erneut testen

Ohne USB bauen · Prüfung durch Lehrkraft vor USB

  1. Lasst den geprüften Sensor und Echo-Spannungsteiler liegen.
  2. Ergänzt Buzzer, Transistor und 1-kΩ-Basiswiderstand nach dem kombinierten Schaltplan.
  3. Prüft 5 V, gemeinsame Masse, Spannungsteiler-Knotenpunkt und Transistor E/B/C.
  4. Verbindet USB wieder und führt den Entfernungstest erneut aus.
  5. Führt den Buzzer-Test erneut aus.
  6. Öffnet erst danach 03_proximity_alarm.py.
Fällt ein Komponententest aus, stoppt und repariert diese Schicht. Das kombinierte Programm dient nicht zur Diagnose zweier ungeprüfter Schaltungen.

Tagesaufgabe

Prototyp eines Näherungsalarms

Code prüfen

  1. Verfolgt None durch alle drei Funktionen.
  2. Findet jeden Grenzwertvergleich.
  3. Findet den Dictionary-Zugriff.

Verhalten prüfen

  1. Zeigt safe, caution und stop.
  2. Richtet den Sensor weg, um invalid zu erzeugen.
  3. Drückt Stop und prüft, ob Licht und Ton ausgehen.

Ungültige Eingaben dürfen nie einen Daueralarm auslösen.

Abschlussfrage

Warum ist ein Timeout nötig?

Erklärt, was das Programm ohne Echo tun soll und warum die Rückgabe von None besser ist als die Rückgabe von 0.

Tag 4 geschafftAusgaben stoppen · USB trennen · geprüfte Schichten beschriftet lassen
Eine gute Antwort: Der Timeout verhindert endloses Warten, lässt das Programm weiterlaufen und stellt eine fehlgeschlagene Messung mit None statt einer falschen Entfernung null dar.
