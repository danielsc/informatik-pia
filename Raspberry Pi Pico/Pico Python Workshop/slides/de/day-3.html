01

Teil 1 · Funktionen geben Aufgaben einen Namen

Beginnt mit bekannten Funktionsaufrufen

Ihr habt schon Funktionen aufgerufen, bevor ihr eigene geschrieben habt.

Bleibt konkret. Ziel ist Vertrautheit, bevor neue Syntax folgt.

Bekannte Aufrufe

Ein Aufruf führt mit Klammern jetzt eine Aufgabe aus

Anschauen und besprechen · Benennt Funktion und Argument


print("Ready")
sleep_ms(500)
print("Go!")

Funktionsname

Der Name vor den Klammern, zum Beispiel print.

Argument

Der Wert in den Klammern, zum Beispiel "Ready" oder 500.

Die Zeitfunktionen sind vorgegeben. Erkennt, was Python bei jedem Aufruf tun soll.

Verknüpft dies mit den eingebauten Funktionen aus TEALS 3.01. sleep_ms pausiert für Millisekunden und wurde bereits importiert.

Definieren, dann aufrufen

def gibt einer wiederholten Aufgabe einen Namen

In Thonny ausprobieren · Tippt das kurze Beispiel ab und führt es aus


def cheer():
    print("Go, Pico!")

cheer()
cheer()

def cheer():

Definiert die Aufgabe und nennt sie cheer.

cheer()

Ruft die Aufgabe auf. Der Funktionskörper läuft erst, wenn Python den Aufruf erreicht.

Ein Name kann viele wiederholte Zeilen ersetzen.

Anpassung von TEALS 3.02. Betont den eingerückten Funktionskörper. Fragt, was ohne Aufruf von cheer geschieht.

Parameter und Farbdaten

Ein gebündelter RGB-Wert kann an eine Funktion übergeben werden

In Thonny ausprobieren · Gebt den Wert vor dem Hardwareeinsatz aus


GREEN = (0, 30, 0)

def show_colour(colour):
    print("Colour:", colour)

show_colour(GREEN)

RGB-Tupel im Workshop

(red, green, blue) ist in diesem Workshop ein gebündelter Farbwert.

Parameter und Argument

colour ist der Parameter. GREEN ist das beim Aufruf übergebene Argument.

Haltet RGB-Werte niedrig, zum Beispiel 30. So sind die Pixel sichtbar, ohne zu blenden.

Führt das Tupel ausdrücklich als gebündeltes Farbpaket ein; Vorkenntnisse werden nicht vorausgesetzt.

Rückgabe oder Ausgabe

print zeigt einen Wert; return gibt ihn zurück

Anschauen und besprechen · Mit welcher Zeile kann späterer Code entscheiden?


def doubled(number):
    return number * 2

print(doubled(4))
answer = doubled(4)

print(...)

Zeigt jetzt einen Wert an.

return ...

Gibt einen Wert zurück, damit anderer Code ihn speichern, vergleichen oder weitergeben kann.

Gibt eine Funktion eine Farbe nur aus, kann keine andere Funktion damit eine Animation wählen.

Vergleicht wie in TEALS 3.03 return und print. answer = doubled(4) funktioniert nur wegen des Rückgabewerts.

Nur intern gültige Namen

Eine lokale Variable existiert nur während dieses Funktionsaufrufs

Anschauen und besprechen · Welcher Name verschwindet nach dem Aufruf?


def make_blue():
    intensity = 25
    return (0, 0, intensity)
NameBedeutung an dieser Stelle
make_blueder Funktionsname
intensityeine lokale Variable nur für diesen Aufruf

Außerhalb der Funktion kann Python das zurückgegebene Tupel verwenden, aber nicht den nur intern gültigen Namen intensity.

Verknüpft dies mit dem Gültigkeitsbereich aus TEALS 3.04. Wichtig ist: Parameter und Variablen in einer Funktion sind lokal.

Teil 2 · Schleifen und Positionen

Wiederholt ein Muster, ohne die Zeile achtmal zu kopieren

Mit Schleifen besucht ein Codeblock jede Pixelposition.

Leitet von Funktionen zur Wiederholung über. Wiederholten Code kennt die Klasse seit Tag 1.

Eine for-Schleife

range(8) erzeugt 0 bis 7

In Thonny ausprobieren · Sagt alle acht Zeilen voraus, bevor ihr Run drückt


for index in range(8):
    print(index)

range(8)

Erzeugt die Zählwerte 0, 1, 2, 3, 4, 5, 6, 7.

Schleifenkörper

Die eingerückte Zeile läuft einmal pro Wert; index enthält dabei den aktuellen Wert.

Ein Index ist eine Positionsnummer. Unsere acht Pixel haben die Indizes 0 bis 7.

Verbindet TEALS 4.01 und 4.02. Fragt nach range(3). Bindet den Begriff Index an eine Positionsnummer.

Vorhersage: pixels[8] fragt nach einer neunten Position, die dieses Modul nicht hat.

Das Modul ist ringförmig, der Code nummeriert trotzdem von 0 bis 7. Fragt nach erstem, letztem und ungültigem Index.

Verschachtelte Schleifen

Bei jedem äußeren Durchlauf läuft die innere Schleife vollständig
