Raspberry Pi Pico · MicroPython-Workshop

Python in der physischen Welt

Fünf Präsentationen vermitteln die Python-Grundlagen, bevor ihr damit echte Schaltungen steuert.

Tag 1

Bringt Licht ins Spiel

Lernt Python und Thonny kennen, speichert ein Skript und sendet eine geheime Nachricht mit einer LED.

Folien öffnen Tag 2

Lasst es entscheiden

Macht aus Taster- und Potentiometerwerten Entscheidungen und baut ein Reaktionsspiel.

Folien öffnen Tag 3

Wiederverwendbar machen

Fasst wiederholte Aufgaben in Funktionen und Schleifen zusammen und baut ein Pixel-Haustier.

Folien öffnen Tag 4

Sensoren nutzen

Messt Abstände sicher, behandelt fehlende Werte und baut einen Näherungsalarm.

Folien öffnen Tag 5

Einen Parkassistenten bauen

Verbindet Sensor, Entscheidungen, Licht und Ton zu einem getesteten Prototyp.

Folien öffnen

Steuerung: Pfeiltasten oder Leertaste zum Weitergehen, F für Vollbild, S für Notizen und O für die Übersicht.
