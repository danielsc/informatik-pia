# Raspberry Pi Pico firmware

`RPI_PICO-20260824-v1.29.0.uf2` is the official stable MicroPython 1.29.0
firmware for the original Raspberry Pi Pico. It is shared by the Wokwi
simulation and the physical classroom boards.

Official source:
<https://micropython.org/resources/firmware/RPI_PICO-20260824-v1.29.0.uf2>

SHA-256:

```text
e1160e602e277d85920adb5fe741435edccba9ba6ecadc85fdab75252eeff4e9
```

This image is for the original Pico, not the Pico W.
